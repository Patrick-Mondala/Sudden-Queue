Before you install

Windows will warn you

The installer is not signed with an Authenticode certificate, so SmartScreen shows a blue box saying it protected your PC. Choose More info → Run anyway. If Smart App Control is switched on, it will block the installer outright, and the only way past that is to turn it off.

That warning is honest and worth reading. A certificate costs money every year and buys nothing except the absence of the dialog, which is not a good use of a fan project's money — so instead of asking you to trust a badge, here is the checksum. Compare it against the file you downloaded.

certutil -hashfile "Sudden.Queue_x64-setup.exe" SHA256
